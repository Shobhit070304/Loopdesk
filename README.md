# Enterprise RAG

A full-stack **Retrieval-Augmented Generation (RAG)** system built for enterprise use.  
It lets you ingest documents, search them with hybrid semantic + keyword search, and get precise answers generated by Gemini — with a semantic cache layer to avoid redundant LLM calls.

---

## Architecture

```
┌──────────────┐     REST API      ┌───────────────────┐
│  Next.js     │ ◄───────────────► │  FastAPI (Python)  │
│  Frontend    │                   │  Backend           │
└──────────────┘                   └────────┬──────────┘
                                            │
                          ┌─────────────────┼──────────────────┐
                          ▼                 ▼                  ▼
                   ┌─────────────┐  ┌─────────────┐  ┌──────────────┐
                   │  PostgreSQL │  │    Redis     │  │  Google      │
                   │  + pgvector │  │  (cache TTL) │  │  Gemini API  │
                   └─────────────┘  └─────────────┘  └──────────────┘
```

**Key features:**
- 📄 **Document ingestion** — text is chunked and embedded via `gemini-embedding-001`
- 🔍 **Hybrid search** — vector similarity (HNSW) + full-text search (GIN), fused with Reciprocal Rank Fusion (RRF)
- 🧠 **LLM answers** — top chunks are passed to `gemini-2.5-flash` as grounded context
- ⚡ **Semantic cache** — near-identical queries are served from cache (Redis + Postgres), skipping the LLM entirely

## Prerequisites

- [Node.js](https://nodejs.org/) v18+
- [Python](https://www.python.org/) 3.11+

## Quick Start

### 1. Clone the repo

```bash
git clone https://github.com/your-org/enterprise-rag.git
cd enterprise-rag
```

---

### 2. Start the database and Redis

```bash
cd api
docker compose up -d
```

This starts:
- **PostgreSQL** (with pgvector) on port `5433`
- **Redis** on port `6379`

---

### 3. Set up the Backend

```bash
cd api

# Create and activate a virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS / Linux

# Install dependencies
pip install -r requirements.txt

# Configure environment
cp .env.example .env
# Edit .env and fill in your GEMINI_API_KEY, DB_URL, and REDIS_URL

# Start the API server
python -m uvicorn main:app --reload --port 8000
```

API will be available at: **http://localhost:8000**  
Interactive docs at: **http://localhost:8000/docs**

---

### 4. Set up the Frontend

```bash
cd frontend

# Install dependencies
npm install

# Configure environment
cp .env.example .env
# Edit .env if your backend runs on a different URL

# Start the dev server
npm run dev
```

Frontend will be available at: **http://localhost:3000**

## API Reference

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/health` | Health check |
| `POST` | `/ingest` | Ingest a document (chunks + embeds it) |
| `GET` | `/documents` | List ingested document chunks and stats |
| `DELETE` | `/documents/{id}` | Delete a document chunk by ID |
| `POST` | `/retrieve` | Hybrid search — returns ranked chunks |
| `POST` | `/ask` | Full RAG pipeline — returns an LLM answer |

### `POST /ingest`
```json
{ "document_text": "Your full document content here..." }
```

### `POST /ask`
```json
{ "query": "What is the refund policy?", "top_k": 3 }
```
